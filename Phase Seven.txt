# Phase 7 — Offline Stress Testing, Pilot Benchmark vs RMDialer & Production Rollout

Telecalling CRM · Technical implementation specification · Final Master Milestone

Phase 7 is the **culminating and final phase** of the entire Telecalling CRM Master Plan ([PLAN.md](PLAN.md)). It synthesizes the native Kotlin telephony engine (Phase 1), backend core and sync pipeline (Phase 2), offline-first telecaller mobile app (Phase 3), supervisor web dashboard (Phase 4), auto-dialer queue engine (Phase 5), and WhatsApp Business automation (Phase 6) into an enterprise-grade, field-tested production deployment ready to completely decommission and replace RMDialer.

Before onboarding the full fleet of 50 telecallers, the system must undergo rigorous offline stress testing, head-to-head benchmarking against legacy RMDialer across 5,000 lead allocations, regulatory compliance audit sign-off (DPDP Act 2023 & TRAI regulations), automated database backup orchestration, and multi-container production deployment via Docker Compose.

## 1. What are we building in Phase 7?

We are building the **Production Infrastructure, Offline Stress Test Harness, and Pilot Benchmarking Engine** spanning the entire repository:

- **1. Comprehensive Offline Stress Test Pack (Section 16 in PLAN.md):**
  - **Large Offline Batch:** 50 calls queued offline, ingested via batch, replayed to verify zero duplicates.
  - **Process Death Mid-Shift:** App killed while calls occur; reconcile endpoint recovers missed calls into disposition queues.
  - **Reassign While Offline:** Manager reassigns lead while caller is disconnected; change feed advances cleanly.
  - **Clock Drift Tolerance:** Ingests calls with local phone clock skewed ±2 hours without corrupting timeline.
  - **Silent Token Rotation:** Verifies access token refresh without interrupting active calling queues.
  - **Backlog Processing:** Queues 20+ mutations (`CALL_CAPTURED`, `DISPOSITION_SAVED`) and pushes in a single atomic batch.
  - **Dual SIM Switching:** Call logs preserve exact SIM slot (SIM 1 vs SIM 2) for multi-SIM telecallers.
  - **Recording Coverage Audit:** Automated computation of connected calls ≥10s with matched audio files.

- **2. Head-to-Head Pilot Benchmark Engine vs RMDialer:**
  - Pilot telemetry tracker comparing SolarCRM vs RMDialer across 5 core KPIs:
    1. Daily dials per telecaller (Target: ≥150 dials/day).
    2. Connect rate percentage (Target: ≥70% connect rate).
    3. Call recording coverage on supported OEM hardware (Target: ≥98%).
    4. Disposition logging velocity (Target: ≤3 seconds post-call).
    5. Telecaller satisfaction score (NPS / usability).
  - Benchmark analytics endpoint (`GET /reports/benchmark`) rendering comparative charts on the supervisor web dashboard.

- **3. Production Multi-Container Orchestration (`docker-compose.prod.yml`):**
  - Hardened multi-container stack:
    - `api`: NestJS 12 production container with health checks, connection pooling, and Swagger docs.
    - `web`: Next.js 16 standalone production build.
    - `postgres`: PostgreSQL 16 with tuned shared buffers, WAL archiving, and persistent volumes.
    - `minio`: Distributed S3-compatible private object storage with automated bucket provisioning (`recordings`).
    - `nginx`: Reverse proxy with SSL/TLS termination, HTTP/2, gzip compression, and rate limiting.
    - `backup-cron`: Automated daily `pg_dump` container shipping encrypted database backups to cold storage.

- **4. Production Secret Hygiene & Security Hardening:**
  - Automated rotation script (`scripts/rotate-secrets.sh`) generating cryptographically secure 256-bit secrets for JWT, database passwords, MinIO access keys, and webhook tokens.
  - Permanent enforcement of `.gitignore` preventing `.env` leaks.

- **5. DPDP & TRAI Regulatory Compliance Audit Matrix:**
  - Formal compliance sign-off validating:
    - Mandatory verbal recording disclosure on Lead Preview Card.
    - DPDP-compliant `Consent` records for call recording and WhatsApp messaging.
    - TRAI calling-hours time-fencing (09:00 - 20:00 IST).
    - Inbound keyword opt-out (`STOP` / `UNSUBSCRIBE` ➔ automatic `dnd: true`).

- **6. Telecaller Onboarding & Sideload Distribution Portal:**
  - Comprehensive OEM calibration guide for Samsung One UI, Xiaomi HyperOS, Vivo Funtouch OS, and Oppo/Realme ColorOS.
  - Web download portal (`/download`) hosting direct signed release APK downloads with SHA-256 checksum verification.
